# فهرس الوثائق

## النشر

`deployment/` يحتوي ملاحظات إعدادات نشر بديلة أو تاريخية. نشر Anime NOVA الفعلي موضح في `../replit.md`.

## المشروع

`project/` يحتوي خطط Nova 2 وملاحظات واجهة الويب وخطة تحقيق الدخل.

## البحث والتدقيق

`research/` يحتوي تقارير المصادر، مراجعات الكتالوج، وتحليل Nova 1 المستخدم مرجعاً لعقود API.

التقارير البحثية قد تصف حالة وقت إعدادها؛ تحقّق من المصدر والكود الحاليين قبل تطبيق توصية قديمة.
