# Anime NOVA — Android Native

تطبيق Android أصلي لمنصة Anime Nova، يعمل من نفس الحزمة على الهاتف والتابلت
والتلفاز. هذه هي بداية استبدال عميل React Native بعميل Kotlin مباشر، مع واجهة
متكيفة وتركيز واضح للريموت.

## حدود المشروع

- الحزمة: `com.nova.anime`
- الاسم الظاهر: `Anime NOVA`
- الهوية التي يرسلها التطبيق للخادم: `nova-anime-mobile-v1`
- الإصدار: `3.0.0` / `versionCode 300`
- الخادم والـAPI مشتركان مع نسخة الموبايل.
- المشغل مبني على AndroidX Media3/ExoPlayer مع Buffer متوازن للبث المباشر
  وبدون مكتبات WebView أو جسور React Native.
- لا يعتمد على Expo أو React Native.
- تم تحليل APK Anime Slayer المرخّص كمرجع نقل، ثم إعادة تنفيذ الوظائف القابلة
  للصيانة داخل مصدر Nova الأصلي. لا يعتمد التطبيق على حزمة Anime Slayer أو
  خوادمها أو مفاتيحها.
- تمت إضافة مكتبة محلية للمفضلة وسجل المتابعة، مع المحافظة على واجهة الهاتف
  والتابلت والتلفاز وربط مصادر التشغيل عبر API Nova فقط.
- يميّز ملف الواجهة بين الهاتف والتابلت والتلفاز تلقائياً لتغيير عدد الأعمدة
  وأحجام البطاقات والمسافات، مع تعطيل RecyclerView animations.
- **قاعدة المطابقة:** لا تحذف Anime NOVA أي صفحة أو زر أو مسار موجود في Nova Mobile.
  الموجود حالياً هو الأساس الأول للنقل، ولا تُعتبر النسخة بديلاً نهائياً قبل
  إكمال نقل الرئيسية والبحث والتصفح والمدبلج والأخبار والتنزيلات والمكتبة
  والجدول والملف الشخصي والإعدادات والتعليقات وكل شاشات التفاصيل والمشاهدة.
  التحسين المسموح به هو تقليل الحركات والانتقالات فقط، وليس تقليل الوظائف.

## البناء

هذا المشروع يُبنى من GitHub Actions عبر Workflow مستقل للنسخة الثانية.

`.github/workflows/build-nova-tv-v3.yml`

ملف Workflow الموبايل `.github/workflows/build-apk.yml` لا يعمل على هذا
الفرع، ولا يتم استدعاؤه من Workflow التلفاز. الناتج يُرفع كـGitHub Artifact
باسم `Nova-3-debug`.

لا يُشغّل هذا المشروع أو يُبنى داخل Replit؛ Replit مستخدم لتعديل المصدر فقط.

## الوظائف الحالية

- كتالوج رئيسي بثلاثة صفوف.
- بحث بالريموت ولوحة المفاتيح الافتراضية.
- تفاصيل الأنمي والحلقات.
- فحص مصادر التشغيل عبر SSE.
- اختيار المصدر وتشغيل HLS/MP4 عبر Media3.
- ترجمة VTT/SRT عند إرسالها من الخادم.
- واجهة adaptive للهاتف والتلفاز وD-pad focus واضح.
- أحجام بطاقات وأعمدة وأزرار تتغير تلقائياً حسب الشاشة.
- صور البطاقات تُفكك بحجم مناسب مع Cache ذاكرة مشترك.

هذه القائمة تصف أساس Nova 3 الحالي وليست قائمة الوظائف النهائية. الهدف هو
مطابقة كل وظائف وأزرار `artifacts/nova-mobile` مع تنفيذ Native أخف، مع إبقاء
نسخة React Native سليمة حتى اكتمال المطابقة.

## ملاحظات الخادم

تستخدم Nova 3 هوية عميل الموبايل الرسمية الحالية والحزمة الإنتاجية نفسها،
لذلك لا تحتاج إلى تعديل بوابة حماية API أو إنشاء مسار مصادقة جديد.
