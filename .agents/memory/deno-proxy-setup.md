## Rule
Route ONLY anime episode link scraping through Deno proxy when `DENO_PROXY_URL` env var is set. All user data (auth, history, favorites, cache) stays in Supabase.

**Why:** Replit datacenter IPs (35.200.x.x range) are blocked by hianime.to, anime3rb.com, animepahe.ru, gogoanime.so, and others. Deno Deploy uses different IPs.

## How to apply
The `denoProxyGet(url, referer, extraHeaders, timeoutMs)` function in anime.ts:
- Returns `null` if `DENO_PROXY_URL` env var not set
- Health-checks proxy every 120s
- Passes `X-Proxy-Key: {DENO_PROXY_SECRET}` header for auth
- Only for scraping (HTML fetching), never for auth or storage operations

## Files
- `scripts/deno-proxy/main.ts` — Deno Deploy function (HTTP proxy with X-Proxy-Key auth)
- `scripts/deno-proxy/deploy.sh` — automated deploy script using Deno Deploy REST API
- `artifacts/api-server/src/routes/anime.ts` — `denoProxyGet()` function at ~line 210

## Deploy steps (needs valid token)
```bash
DENO_TOKEN=ddp_xxx bash scripts/deno-proxy/deploy.sh
```
Then add to Replit Secrets:
- `DENO_PROXY_URL` = `https://anime-nova-proxy.deno.dev`
- `DENO_PROXY_SECRET` = (generated by deploy script)

## Blocked sites to test via Deno (from Replit: blocked)
- hianime.to → HTTP 000 (CF-blocked)
- animepahe.ru → HTTP 000 (CF-blocked)
- gogoanime.so → HTTP 000 (CF-blocked)
- anime3rb.com → HTTP 403 (IP-blocked by CF Managed Challenge)

## Token format
Deno Deploy personal access tokens start with `ddp_`. Generated at:
https://dash.deno.com/account#access-tokens
