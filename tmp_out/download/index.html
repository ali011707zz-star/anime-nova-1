الخطوات بالترتيب

  1. حمّل الملفين من الأزرار فوق (من متصفح الموبايل نفسه)
  2. نصّب الشهادة: Settings → Security → Install a certificate → CA certificate → اختر الملف اللي حمّلته
  3. نصّب ملف APK (لازم تسمح بالتنصيب من مصادر غير معروفة "Unknown sources" لو طلب منك)
  4. روح Settings → Wi-Fi → دوس مطول على الشبكة المتصلة بيها → Modify network → Advanced → Proxy: Manual
    Host: 95.182.93.105 — Port: 8899
  5. افتح التطبيق (النسخة المعدّلة) وشغّل حلقة عربية عادي
  6. رجّع لي وقولي "خلصت"
