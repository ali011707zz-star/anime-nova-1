# أرشيف نماذج Android TV

هذا المجلد يحفظ المصدر التاريخي لثلاثة نماذج Android الأقدم:

- `nova-tv/` — نموذج TV خفيف.
- `nova-tv-v2/` — نموذج Kotlin أحدث يعمل على الهاتف والتلفاز.
- `nova-tv-v3/` — نقل Kotlin غير مكتمل؛ ليس تطبيق التلفاز الحالي.

تم نقل النماذج غير النشطة إلى هذا المجلد لتوضيح أنها ليست تطبيق التلفاز الحالي. لم تُحذف ملفات أو بيانات.
لا يحتوي المستودع الحالي على workflows البناء اللذين كانت تشير إليهما README القديمة.
