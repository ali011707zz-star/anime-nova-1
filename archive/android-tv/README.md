# أرشيف نماذج Android TV

هذا المجلد يحفظ المصدر التاريخي لنسختي Android الأقدم:

- `nova-tv/` — نموذج TV خفيف.
- `nova-tv-v2/` — نموذج Kotlin أحدث يعمل على الهاتف والتلفاز.

تم نقلهما من جذر المستودع لتوضيح أنهما غير نشطين. لم تُحذف ملفات أو بيانات.
لا يحتوي المستودع الحالي على workflows البناء اللذين كانت تشير إليهما README القديمة.

النموذج `nova-tv-v3/` بقي في مساره الحالي؛ README الخاص به يوضح أنه نقل Kotlin غير مكتمل.
