# Nova TV 2

> **مؤرشف:** هذا مصدر تاريخي محفوظ للرجوع إليه، وليس إصداراً نشطاً أو مسار البناء الحالي.

تطبيق Android أصلي خفيف لمنصة Anime Nova، يعمل من نفس الحزمة على الهاتف
والتلفاز. الواجهة مستوحاة من أنماط تطبيقات الأنمي الأصلية: درج وتنقل بسيط،
بطاقات قابلة للتركيز، وشبكات متكيفة حسب حجم الشاشة.

## حدود المشروع

- الحزمة: `com.nova.anime.tv.v2`
- الاسم الظاهر: `Nova TV`
- الهوية التي يرسلها التطبيق للخادم: `nova-anime-tv-kotlin-v2`
- الخادم والـAPI مشتركان مع نسخة الموبايل.
- المشغل مبني على AndroidX Media3/ExoPlayer مع LoadControl صغير نسبياً.
- لا يعتمد على Expo أو React Native.
- تم تحليل APK Anime Slayer المرخّص كمرجع نقل، ثم إعادة تنفيذ الوظائف القابلة
  للصيانة داخل مصدر Nova الأصلي. لا يعتمد التطبيق على حزمة Anime Slayer أو
  خوادمها أو مفاتيحها.
- تمت إضافة مكتبة محلية للمفضلة وسجل المتابعة، مع المحافظة على واجهة الهاتف
  والتلفاز وربط مصادر التشغيل عبر API Nova فقط.

## الحالة

نُقلت النسخة إلى `archive/android-tv/nova-tv-v2`. لا يتضمن المستودع الحالي
workflow لبناء هذه النسخة. حُفظت ملفات المصدر كما هي؛ لا تعتمد عليها كإصدار
قابل للبناء أو التوزيع.

## الوظائف الحالية

- كتالوج رئيسي بثلاثة صفوف.
- بحث بالريموت ولوحة المفاتيح الافتراضية.
- تفاصيل الأنمي والحلقات.
- فحص مصادر التشغيل عبر SSE.
- اختيار المصدر وتشغيل HLS/MP4 عبر Media3.
- ترجمة VTT/SRT عند إرسالها من الخادم.
- واجهة adaptive للهاتف والتلفاز وD-pad focus واضح.
- أحجام بطاقات وأعمدة وأزرار تتغير تلقائياً حسب الشاشة.
- صور البطاقات تُفكك بحجم مناسب مع Cache ذاكرة مشترك.

## ملاحظات الخادم

يجب أن تكون نسخة API المنشورة متضمنة لهوية Nova TV 2 في
`artifacts/api-server/src/lib/security.ts` و`artifacts/api-server/src/app.ts`.
هذا لا يغيّر قواعد هوية تطبيق الموبايل.
