# Anime Slayer 1.5.5 — JADX extraction

تم إنشاء هذا المجلد بأداة JADX 1.5.0 من APK مصرح بتحليله من صاحب المشروع.

- `sources/`: كود Java/Kotlin المفكك
- `resources/`: AndroidManifest والموارد والأصول
- `input/anime-slayer.apk`: APK الأصلي المستخدم
- `../README.md`: شرح حدود التوافق مع مشروع Expo

JADX لا يستعيد ملفات Kotlin/Java الأصلية أو تاريخ المشروع، وقد يفشل في بعض
الأجزاء المضمنة أو المحمية. لا تُعامل هذه الملفات كبديل مباشر لمصدر البناء.
