# Nova Mobile 2

نسخة Android أصلية مبنية من كود تطبيق Anime Slayer 1.5.5 المفكك بواسطة
JADX 1.5.0. تم إبقاء حزم Java الأصلية حتى يعمل الكود المفكك دون إعادة تسمية
واسعة، مع تغيير هوية التطبيق وعنوان الـAPI فقط.

## الهوية

- اسم التطبيق: `Nova Mobile 2`
- Application ID: `com.nova.anime2`
- الإصدار: `2.0.0`
- API الأساسي: `https://animenovaa.duckdns.org/`
- الأيقونة: الأيقونة المستخرجة من APK المصدر

## محتويات المشروع

- `app/src/main/java` — 6,169 ملف Java صادر من JADX.
- `app/src/main/res` — موارد Android الأصلية المستخرجة.
- `app/src/main/jniLibs` — المكتبات الأصلية المطلوبة من التطبيق.
- `app/src/main/assets` — أصول التطبيق.
- `extracted/anime-slayer-1.5.5` — نسخة مرجعية غير معدلة من ناتج JADX.

هذا مشروع Gradle/Android أصلي، وليس مشروع Expo أو React Native. لم يتم تثبيت
تبعياته أو بناؤه أو تشغيله داخل Replit؛ مكان البناء المستهدف هو الـVPS/CI
الخارجي.

## ملاحظات المصدر المفكك

ناتج JADX ليس المصدر الأصلي حرفياً وقد يحتوي أخطاء فكّ محدودة. لذلك تم
الاحتفاظ بالاستخراج الكامل منفصلاً، بينما يمثل مجلد `app` مشروع البناء الأصلي
المجهز للتطوير والبناء خارج Replit.
